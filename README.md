# 🎮 Jogo da Velha em Python

Meu primeiro projeto desenvolvido em Python.

Este projeto é um jogo da velha executado pelo terminal, desenvolvido para praticar os fundamentos da programação.

## 🧠 O que pratiquei

* Variáveis
* Listas
* Estruturas condicionais (`if` e `else`)
* Laços de repetição (`for`)
* Entrada de dados com `input()`
* Manipulação de listas

## ▶️ Como executar

É necessário ter o Python instalado.

No terminal, execute:

```bash
python main.py
```

Este projeto faz parte dos meus estudos de programação e representa um dos meus primeiros projetos utilizando Python.
